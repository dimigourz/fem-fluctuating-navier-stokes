# A Finite Element Method for Fluctuating Navier–Stokes Equations

This repository contains the code associated with the paper **“A Finite Element Method for Fluctuating Navier–Stokes Equations.”**

Authors: D. Gourzoulidis, M. Gallo, S. Elkantassi, T. Kay, and S. Kalliadasis.

The code and instructions required to reproduce the numerical experiments will be added here.
